
# Семантичний пошук наукових статей arXiv

## Опис проєкту

У цій домашній роботі я створила систему семантичного пошуку наукових статей із датасету arXiv.

Основна ідея — знаходити статті не тільки за конкретними словами, а й за змістом пошукового запиту.

Для цього я використала модель SPECTER2, яка перетворює тексти на числові вектори, та Pinecone для їх зберігання і пошуку.

## Використані технології

- Python 3.11
- Pandas та NumPy
- PyTorch
- Transformers
- SPECTER2
- Pinecone
- Scikit-learn
- Hugging Face

## Датасет

Для роботи я використала Cornell arXiv Dataset із Kaggle.

Посилання:
https://www.kaggle.com/datasets/Cornell-University/arxiv

Оригінальний датасет досить великий, тому я підготувала окрему вибірку з 8000 статей.

Характеристики вибірки:

- Кількість статей: 8000
- Роки публікацій: 2007–2025
- Кількість категорій: 148
- Приблизно 421–422 статті з кожного року

Для кожної статті зберегла ID, назву, анотацію, авторів, рік та категорію.

Підготовлені дані знаходяться у файлі `data/arxiv_subset.parquet`.

## 1. Підготовка даних

Скрипт: `scripts/01_prepare_data.py`

Спочатку я очистила тексти від зайвих пробілів і переносів рядків.

Також визначила рік публікації за датою першої версії статті та виділила основну категорію.

Щоб можна було перевіряти пошук за різними роками, сформувала вибірку з приблизно однаковою кількістю статей за кожен рік.

## 2. Створення ембеддингів

Скрипт: `scripts/02_embed.py`

Для створення векторних представлень використала модель SPECTER2.

Я об'єднала назву та анотацію кожної статті, після чого модель перетворила текст на вектор.

Результат:

- Кількість ембеддингів: 8000
- Розмірність вектора: 768
- Форма масиву: (8000, 768)

Ембеддинги збережені у файлі `embeddings/embeddings.npy`.

## 3. Завантаження в Pinecone

Скрипт: `scripts/03_load_to_pinecone.py`

Для зберігання векторів використала Pinecone.

Створила індекс `arxiv-semantic-search` із такими параметрами:

- Розмірність: 768
- Метрика: cosine
- Кількість завантажених векторів: 8000

Разом із векторами завантажила метадані статей: назву, анотацію, авторів, рік та категорію.

Це дозволило використовувати додаткові фільтри під час пошуку.

## 4. Семантичний пошук

Скрипт: `scripts/04_search.py`

Для тестування використала запит:

"machine learning methods for image classification"

Перевірила три варіанти пошуку:

1. Без фільтрів.
2. З фільтром за 2020 роком.
3. З фільтром за категорією cs.CV.

Усі три варіанти працювали правильно.

Наприклад, система знайшла статтю:

"Butterfly Detection and Classification Based on Integrated YOLO Algorithm"

Ця стаття відповідає темі запиту, оскільки YOLO використовується для виявлення та класифікації об'єктів на зображеннях.

Показники cosine similarity у результатах пошуку були приблизно від 0.82 до 0.87.

Я побачила, що семантичний пошук дозволяє знаходити тематично схожі статті навіть без точного збігу всіх слів у запиті.

## 5. Порівняння стратегій chunking

Скрипт: `scripts/05_chunking.py`

У цій частині я перевірила, як розбиття тексту на фрагменти впливає на пошук.

Для експерименту використала 100 випадково вибраних статей.

Порівняла три стратегії:

1. Full text — текст без розбиття.
2. Fixed-size — фрагменти по 100 слів із перекриттям 20 слів.
3. Sentence-based — розбиття за реченнями.

Результати:

| Стратегія | Кількість фрагментів | Найвища cosine similarity |
|-----------|----------------------|--------------------------|
| Full text | 100 | 0.8122 |
| Fixed-size | 205 | 0.8516 |
| Sentence-based | 202 | 0.8445 |

Найвищий показник схожості отримала стратегія fixed-size.

Але це не означає, що вона завжди найкраща. Для точнішого висновку потрібно оцінювати не лише similarity score, а й релевантність знайдених статей.

Результати експерименту збережені у файлі `data/chunking_results.csv`.

## Висновки

Під час виконання роботи я навчилася готувати дані для семантичного пошуку, створювати ембеддинги та працювати з векторною базою Pinecone.

Також перевірила, як працює пошук із фільтрами за роком і категорією.

Найцікавішим для мене було порівняння різних стратегій chunking. Я побачила, що навіть для однакового запиту результати можуть змінюватися залежно від того, як ми підготували текст.

У результаті мені вдалося створити працюючу систему семантичного пошуку для 8000 наукових статей.

## Як запустити проєкт

1. Створити віртуальне середовище Python 3.11.
2. Встановити залежності:

   pip install -r requirements.txt

3. Створити файл `.env` із параметрами:

   PINECONE_API_KEY=your_api_key
   PINECONE_INDEX=arxiv-semantic-search

4. Завантажити датасет arXiv із Kaggle та помістити файл
   `arxiv-metadata-oai-snapshot.json` у папку `data`.

5. Послідовно запустити скрипти:

   python scripts/01_prepare_data.py

   python scripts/02_embed.py

   python scripts/03_load_to_pinecone.py

   python scripts/04_search.py

   python scripts/05_chunking.py

## Безпека

API-ключ Pinecone зберігається у файлі `.env`.

Цей файл не додається до GitHub завдяки `.gitignore`.
